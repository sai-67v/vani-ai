# Technology Stack

## Frontend (Dashboard)
- **Framework**: Next.js 15 (App Router)
- **Language**: TypeScript / TSX
- **Styling**: TailwindCSS, Radix UI primitives, Framer Motion, Unicorn Studio React
- **Icons**: Lucide React
- **Client/State**: React 19

## Backend (Vani A.I. Engine)
- **Framework**: Express.js (Node.js)
- **Language**: JavaScript
- **Validation**: Zod
- **WebSocket**: `ws` package for media streams
- **Audio Processing**: `wavefile`

## Database & Authentication
- **Service**: Supabase
- **Client Libraries**: `@supabase/supabase-js`, `@supabase/ssr`

## Testing
- **Unit Testing**: Jest
- **E2E Testing**: Playwright
