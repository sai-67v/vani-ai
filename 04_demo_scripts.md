# Demo Scripts — 5 End-to-End Conversations

> Each script follows the flow: **FAQ → Qualify → Callback**  
> `A` = Agent (Ava) · `C` = Caller  
> Estimated duration: 90–120 seconds each

---

## Script 1 — Pricing enquiry → Hot lead (English)

| # | Speaker | Dialogue |
|---|:---:|---|
| 1 | A | Hi! Thanks for calling VoiceFlow Solutions. I'm Ava — how can I help you today? |
| 2 | C | Yeah, hi. I wanted to know how much your AI voice agent costs. |
| 3 | A | Sure! We have three plans. Starter is ₹4,999 per month, Growth is ₹14,999, and Enterprise is custom-priced. All come with a free 14-day trial. Which one sounds closest to what you need? |
| 4 | C | The Growth plan sounds about right. We make around 1,500 calls a month. |
| 5 | A | Growth would be perfect for that — it includes 2,000 minutes and CRM integration. Just so I can help you better — are you looking to get started within the next 30 days? |
| 6 | C | Actually, yes. We want to go live by next month. |
| 7 | A | That's great. And do you already have a budget set aside for this? |
| 8 | C | Yes, we've already got approval from management. |
| 9 | A | Wonderful — it sounds like we can really help you right away. Let me book a 15-minute call with a specialist. Would tomorrow at 11 AM work? |
| 10 | C | Yeah, that works. |
| 11 | A | Done! You'll get a calendar invite shortly. Is there anything else I can help with? |
| 12 | C | No, that's it. Thanks! |
| 13 | A | Thank you, and have a great day! |

**Qualification**: 🔴 Hot — Timeline within 30 days, budget approved.

## Script 4 — Discount enquiry + interruption → Warm lead (English)

| # | Speaker | Dialogue |
|---|:---:|---|
| 1 | A | Hi! Thanks for calling VoiceFlow Solutions. I'm Ava — how can I help you today? |
| 2 | C | Do you have any discounts right now? |
| 3 | A | Yes! New customers get 25% off the first 3 months with code VOICE25. We also— |
| 4 | C | *(interrupts)* Wait, does that apply to annual billing too? |
| 5 | A | Great question. The VOICE25 code applies to monthly billing. But annual billing already saves you 20% — that's two months free. Would you like to compare both options? |
| 6 | C | Hmm, maybe. We're a startup — do you have any special startup pricing? |
| 7 | A | We do! Verified startups get 40% off. I can send you the application link. Are you looking to get started in the next 30 days? |
| 8 | C | Probably in the next couple of months once our funding closes. |
| 9 | A | Understood. And would you be the decision-maker, or would someone else need to approve? |
| 10 | C | I'd need to talk to my co-founder. |
| 11 | A | Makes sense. Can I schedule a call for both of you with our team this week? |
| 12 | C | Sure, let me check — Wednesday works. |
| 13 | A | I'll set that up for Wednesday morning. You'll get a calendar invite. Thanks for calling! |

**Qualification**: 🟡 Warm — Timeline 1–3 months, needs co-founder approval. Interruption handled cleanly at turn 4.
